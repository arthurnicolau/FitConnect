# FitConnect

Aplicativo para encontrar parceiros de treino perto de você: corrida, pedal, yoga, futebol e mais.

> Protótipo: os dados ainda são simulados e ficam só na memória (somem ao recarregar a página).

## Como rodar

Abra o `index.html` no navegador. No computador, o app aparece dentro de uma moldura de celular; no celular, ocupa a tela inteira.

Para testar como app instalável (PWA), sirva a pasta por HTTP, por exemplo:

```
npx serve .
```
